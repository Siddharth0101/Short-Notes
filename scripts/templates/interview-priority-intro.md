# Interview priority — quick revision

- Selection — 52 technical questions; learning shortlist hai, company-frequency ranking nahi.
- Method — pehle answer bolo, phir check; weak topic repeat karo.
- Sources — [Amazon topics](https://www.amazon.jobs/content/en/how-we-hire/interview-prep/software-development-topics) aur [Microsoft guidance](https://careers.microsoft.com/v2/global/en/hiring-tips/technical-interviewing).
- Role — actual interview scope recruiter/job description se match karo.

## Apna route

- Frontend — JS → HTML/CSS → React → DSA → machine coding/design.
- Java backend — Java → SQL → Spring → DSA → LLD/system design.
- Node backend — JS async → HTTP/streams → MongoDB → auth/recovery.
- General SWE — strong language + DSA + tests + OOP/OS/network basics.

## Answer ka format

- Contract — input/output, constraints aur assumptions.
- Approach — correct baseline, phir optimization.
- Reason — invariant/state ownership kyun correct hai.
- Cost — time, memory aur important tradeoff.
- Verify — normal, boundary aur failure case.
- Follow-up — requirement badle toh decision kaise badlega.

## Coding checklist

- Arrays — frequency map, pointers, window aur prefix sums.
- Lists — reverse/cycle; empty aur single-node cases.
- Search — sorted/monotonic input aur shrinking interval.
- Trees/graphs — visited, cycle, ordering aur weight assumptions.
- DP — state, transition, base case aur fill order.
- UI/API — stable identity, race handling, validation aur recovery.

## 14-session route

- 1–2 — language/output; personal mistake list.
- 3–4 — hashing, pointers/window, binary search.
- 5–6 — lists, trees, graphs, DP.
- 7–8 — frontend/backend implementation drill.
- 9–10 — SQL/concurrency/LLD ya frontend performance.
- 11–12 — system design + OS/network debugging.
- 13 — project/behavioral mock.
- 14 — mixed mock + weak-topic retry.

## Project aur behavioral

- Disagreement — shared goal, evidence, decision aur tradeoff.
- Mistake — ownership, impact, fix aur prevention; real example do.
- Ambiguity — missing assumptions clear karke small reversible step.
- Customer impact — actual result; invented metric mat bolo.
- Contribution — tumhara work, hardest decision aur verification.
- Feedback — kya badla aur uska observable result.

## Self-check

- Score — 0 unclear, 1 hint chahiye, 2 independently solve/explain.
- Retry — unresolved correctness error wale topic ko revisit karo.
- Sync — answers canonical app bank se generate hote hain.
