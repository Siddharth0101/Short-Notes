## Main Coverage

- Values, variables, types, operators, control flow (fundamentals part 1)
- Strict mode, functions, arrays, objects, loops (fundamentals part 2)
- JS engine, execution context, call stack, scope chain, hoisting, TDZ
- DOM selectors, events, delegation, propagation, IntersectionObserver, DOM traversal
- How the web works (client-server, HTTP, DNS, TCP/IP)
- Destructuring, spread/rest, short-circuiting, nullish coalescing, optional chaining, Sets, Maps, strings
- Default params, higher-order functions, closures, IIFE, call/apply/bind
- Array methods: map, filter, reduce, find, sort, flat, chaining
- Numbers, dates, Intl formatting, setTimeout, setInterval
- `this` keyword, call, apply, bind
- Constructor functions and classes (OOP)
- Event loop, promises, async/await
- ES6 modules, CommonJS, bundling, transpiling, polyfilling
- Developer skills, debugging, breakpoints, logical assignment operators (&&=, ||=, ??=), ES2023+ change-by-copy array methods (toSorted, toReversed, toSpliced, with)
- Regular expressions
