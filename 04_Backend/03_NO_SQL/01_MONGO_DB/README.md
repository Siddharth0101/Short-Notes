# MongoDB Short Notes

These folders keep the MongoDB/Mongoose part of the Jonas Node course together.
Auth, error handling, SSR, and advanced features are app-layer topics, but in this course they are built on the MongoDB Natours project, so they live here for reading flow.

## Suggested Reading Order

1. `01_DATABASE/MongoDB_Mongoose_Basics.js`
2. `02_ERROR_HANDLING/Express_Error_Handling.js`
3. `03_AUTH_SECURITY/Auth_Authorization_Security.js`
4. `04_ADVANCED_MONGOOSE/Data_Modeling_Advanced_Mongoose.js`
5. `05_SERVER_RENDERING/Pug_Server_Side_Rendering.js`
6. `06_ADVANCED_FEATURES/Payments_Email_File_Uploads.js`

## Main Coverage

- MongoDB CRUD, Atlas, Compass
- Mongoose schemas, models, validation, middleware
- Express error handling with Mongoose errors
- JWT auth, users, password reset, cookies, security
- Advanced Mongoose data modeling, refs, populate, geospatial queries
- Pug SSR, Stripe payments, email, uploads, image processing
