# Revision format

- Source notes — 142 original files bhi short Hinglish revision format mein hain.
- Chapters — 108 chapters ko short Hinglish points mein rewrite kiya hai.
- Style — `term — meaning / zaroori catch`; long explanations hata di hain.
- Code — optional [examples](../examples/README.md) mein preserved hai.
- Sources — chapter ke official links aur research anchors preserved hain.
- Route — [syllabus](README.md) se apna subject kholo.
- Coverage recheck — [audit](COVERAGE_AUDIT.md) mein subject counts aur newly covered topics dekho.
- Density — bigger chapters mein small topic groups; new points 28 words ya kam.
