# System design references

Start with the new [React frontend and Java backend study path](../notes/README.md#system-design). It covers requirements, capacity estimates, frontend architecture and performance, Java APIs, caching, messaging, reliability, security, and worked case studies.

These folders preserve the earlier, more detailed source references:

1. `01_NAMASTE_REACT_LLD` — component architecture, reconciliation, hooks, state, routing, testing.
2. `02_FRONTEND_HLD_CHIRAG_GOEL` — frontend design frameworks, rendering, storage, network, performance, accessibility and security.
3. `03_CASE_STUDIES_HLD_LLD` — feeds, chat, autocomplete, streaming, commerce, email and collaborative apps.
4. `04_BACKEND_FOR_FRONTEND` — API gateways, API paradigms, caches, databases and rate limits.
5. `05_MACHINE_CODING_PATTERNS` — OTP inputs, progress bars, file explorers and pagination.

Use the app's **Original notes** collection to search these references. Use **Visual lab** to step through React rendering, a Java request lifecycle, and cache invalidation.
