## Main Coverage

- React fundamentals, JSX, props, state, controlled elements
- State management, lifting state up, derived state, immutable updates
- Component composition, children prop, reusable patterns, compound components
- useEffect, cleanup function, data fetching patterns, custom hooks
- Advanced hooks: useRef, useReducer, useMemo, useCallback
- React Router v6: routes, navigation, URL parameters, search params, nested routes, protected routes
- Context API, Context + useReducer mini-Redux pattern
- Performance optimization: memo, code splitting, lazy loading, Suspense
- Redux Toolkit (RTK): store, slices, async thunks, Provider, useSelector, useDispatch
- TanStack React Query (v5): QueryClient, useQuery, useMutation, cache invalidation, Supabase backend integration
- React styling: Styled Components, CSS Modules, Tailwind CSS
